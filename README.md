# Library Management System (C++)

A procedural console-based **Library Management System** developed in C++ using **Functions**. This project allows users to manage library books and operations in a structured and modular way.

---

## 🚀 Features
- **Add Book:** Add a new book to the library system with its details.
- **Display Books:** View a list of all available books in the library.
- **Search Book:** Look up specific books by title or ID.
- **Borrow & Return:** Manage book borrowing and returning operations seamlessly.
- **Modular Design:** Built entirely using well-organized functions for clean and reusable code.

---

## 🛠️ Technologies Used
- **Language:** C++
- **Concepts:** Procedural Programming (Functions, Arrays/Vectors, Control Structures)
- **Environment:** Visual Studio

---

## 📂 Project Structure
- `main.cpp`: Contains the main function, user interface menu, and all core system functions.
